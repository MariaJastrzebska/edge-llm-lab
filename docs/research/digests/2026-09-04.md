## Literature sweep: edge-VLM / medical-structured-generation angle
(Last touched iter 21, 5 iterations stale — the queued default per iter 25's
next action, since it's Route A's own application domain and had gone the
longest without a check.)

Three new-to-`seen.json` items, none competitive with G1/Route A's hardware-
cost claim, but one is worth tracking as a baseline-drift/related-work item:

1. **EdgeFM: Efficient Edge Inference for Vision-Language Models** (arXiv
   2604.27476) — a lightweight, agent-driven VLM/LLM inference runtime for
   cross-platform *industrial* edge deployment, explicitly tuned for
   single-request (not batched) low-latency workloads: strips non-essential
   features, encapsulates kernel optimizations as reusable "skills," uses a
   model-/hardware-/stage-aware operator table to dispatch kernels at
   runtime. **Differentiate-from** — it's a general inference-runtime
   speedup (kernel dispatch/latency minimization), not a grammar/constrained-
   decoding-cost paper, so it doesn't compete with Route A's mask-pipelining
   claim. But it's the closest-yet paper to Route A's *systems* framing
   specifically for VLMs (single-stream, edge, deterministic latency) rather
   than medical-report accuracy — joins the **general-purpose
   inference-engine speedup cluster** (BaseRT/MetalRT, Ollama's own MLX
   backend) as its first VLM-specific member, worth a related-work sentence
   if Route A proceeds and a baseline-drift watch item if a technique like
   this ever lands under llama.cpp's mtmd path.
2. **Progressive Semantic Communication for Efficient Edge-Cloud
   Vision-Language Models** (arXiv 2604.26508) — a Meta AutoEncoder that
   compresses visual tokens for adaptive edge-cloud VLM inference under
   bandwidth constraints. **Ignore** — this is edge-*cloud* split computing
   (raw visual data still leaves the device, compressed), same architectural
   shape as the already-filed DynaSplit (iter 9); weakens rather than serves
   Route A's on-device-privacy framing, and no constrained-decoding angle.
3. **Reason Like a Radiologist / BoxMed-RL: Chain-of-Thought and
   Reinforcement Learning for Verifiable Report Generation** (arXiv
   2504.18453) — a two-phase VLM training framework (CoT pretraining +
   RL alignment to bounding boxes) for spatially-verifiable radiology
   reports. **Ignore** — accuracy/explainability-focused, cloud-scale
   training pipeline, no edge-systems or decode-time-latency angle;
   continues the standing pattern (iters 10, 17, 21, 24) that this
   literature area has exactly one differentiate-from paper on file (the
   ACM edge-deployed dual-report paper, iter 10) and no systems-cost/
   constrained-decoding competitor.
