## New-to-`seen.json` items (2)

1. **Grammar-Aligned Decoding** (arXiv 2405.21047, NeurIPS 2024) —
   **differentiate-from**, correctness-tax cluster, fix-side. Formalizes
   "grammar-aligned decoding" (GAD): the problem that grammar-constrained
   decoding (GCD) distorts the LLM's own output distribution — grammatical
   outputs end up with likelihoods that don't match what the LLM itself
   would assign them, which is a *different* mechanistic explanation for
   the correctness-tax gap than CRANE's (iter 34: reasoning-token
   starvation). Proposes ASAp, an adaptive algorithm that starts as GCD and
   converges toward the true LLM distribution, trading efficiency for
   distributional fidelity. No edge/hardware/latency angle. Predates the
   2026 correctness-tax cluster by ~19 months but was never entered until
   this sweep — third "foundational precursor found late" case (after
   PSC/mask-speedup, CRANE/correctness-tax), and now the cluster has *two*
   independent mechanistic (not just empirical) explanations for the
   validity-correctness tradeoff: reasoning-token loss (CRANE) and
   distributional sampling bias (this paper) — worth stating both in a
   related-work paragraph as complementary, not competing, accounts.
2. **SynCode: LLM Generation with Grammar Augmentation** (arXiv 2403.01632,
   UIUC, v4 Nov 2024) — **differentiate-from**, joins the algorithmic
   mask-speedup cluster as a lineage/precursor citation (same role as
   2502.05111, not counted as a numbered member). DFA-based offline mask
   store for CFG-constrained decoding (JSON/SQL/Python/Go), eliminates
   syntax errors entirely on JSON, 96%+ syntax-error reduction on
   Python/Go. Cloud/general-purpose benchmarks, no edge/Joules/
   single-stream angle — same defining trait as every other cluster
   member. Surfaced only because it kept appearing as a citation inside
   other constrained-decoding papers' related work; worth citing as
   foundational lineage alongside 2502.05111, not a new competitor.

Both papers are pre-2026 foundational work that the correctness-tax /
mask-speedup literature keeps citing as background — neither is a scoop,
neither touches edge hardware or energy, and both strengthen rather than
threaten the standing gap statement.
