## Mask-speedup cluster sweep — no new numbered members
Two general queries ("grammar-constrained decoding acceleration mask
computation speedup", "structured decoding edge device latency energy
September 2026") plus a targeted MLSys check. Result: **no new member joins
the 11-strong algorithmic mask-speedup cluster** (PSC, GRID,
Attention-Meets-Reachability, Token-Space-Compression/CFGzip, Pre³,
XGrammar-2, MetaJuLS, Stay Within Your Bounds, Trie Automata, WGRAMMAR,
Earley-Driven Dynamic Pruning/Formatron). Four new-to-`seen.json` items, all
scored **ignore** or **differentiate-from**, none competitive:

1. **SLED: A Speculative LLM Decoding Framework for Efficient Edge Serving**
   (arXiv 2506.09397) — lightweight edge devices (tested on **Jetson Orin
   Nano, Raspberry Pi 4B/5**) draft candidate tokens locally; a shared edge
   server (4x A100) verifies them; reports 2.2x system throughput, 2.8x
   system capacity vs. baselines with no accuracy loss. No grammar/mask
   angle — this is the speculative-decoding-for-edge-serving cluster, not
   the mask-speedup one. Verification happens off-device (edge-server side),
   the same weakens-rather-than-serves on-device-privacy shape as
   DynaSplit/CoVSpec/INAR-VL/LAST — **ignore** for Route A framing. Useful
   regardless as a **third independent Jetson Orin Nano** hardware data
   point (after 2511.11624 iter 31, EdgeCIM iter 32) and the **first
   Raspberry Pi 4B** source — filed for whenever the postponed Jetson
   purchase question (sub-question 5) resurfaces.
2. **The Extrapolation Cliff in On-Policy Distillation of Near-Deterministic
   Structured Outputs** (arXiv 2605.08737, NTU Singapore) — derives a
   closed-form threshold above which on-policy-distillation post-training
   flips from format-preserving to format-collapsing on JSON/structured-
   output tasks. A genuine structured-output failure mode, but at the
   **training-time** (RL/distillation) layer, not inference-time decode
   cost or inference-time accuracy loss — a third layer distinct from both
   the mask-speedup cluster (decode-time mask computation) and the
   correctness-tax cluster (inference-time accuracy loss under constrained
   decoding). **Ignore**, filed only to avoid re-discovery; a possible
   one-line background citation if a related-work section ever needs to
   distinguish inference-time from training-time structured-output failure.
3. **ARCS: Autoregressive Circuit Synthesis with Topology-Aware Graph
   Attention and Spec Conditioning** (arXiv 2603.29068, NYU) — an
   analog-circuit-design generator that uses grammar-constrained decoding
   (topology-aware token masking) as one component to guarantee structural
   validity of generated circuit topologies. Wrong domain entirely
   (EDA/analog-circuit synthesis) and an application-level use of GCD, not
   a systems contribution to GCD itself — **ignore**.
4. **Data-hygiene fix** (same class as iters 22/29/31/32/33/36's fixes):
   **"Future Validity is the Missing Statistic... for Grammar-Faithful
   Speculative Decoding"** (arXiv 2605.07698) had sat in `seen.json` since
   iteration 3 (2026-08-14) as a bare date with no annotation, despite
   already being described in that iteration's own digest. Now annotated:

   of scope for G1's sub-1B single-model regime — **differentiate-from**,
