## New-to-seen.json items

1. **Guiding LLMs The Right Way: Fast, Non-Invasive Constrained Generation**
   / DOMINO (arXiv 2403.06988, ETH Zurich SRI Lab — Beurer-Kellner, Fischer,
   Vechev, submitted Feb 2024)
   Link: https://arxiv.org/abs/2403.06988
   Relevance: constrained decoding forces strict formal-language conformance
   by masking tokens, but naive masking can be architecturally invalid when
   the LLM's sub-word vocabulary doesn't align with the external grammar's
   token boundaries — both slowing generation and, when misaligned,
   degrading task accuracy toward valid-but-suboptimal outputs. DOMINO
   enforces constraints in a fully subword-aligned way, using precomputation
   plus speculative decoding to reach near-zero overhead and, in some cases,
   almost 2x speedup — no cloud/GPU-serving-baseline number given, general
   LLM-serving setting, no edge or Joules angle.
   Verdict: **differentiate-from** — a lineage/precursor citation for the
   algorithmic mask-speedup cluster, same non-numbered-member role as
   2502.05111 and SynCode (2403.01632): predates the 2026 cluster by over two
   years, a fourth "foundational-precursor-found-late" case for this cluster
   specifically (joining 2502.05111, SynCode, and — for the sibling
   correctness-tax cluster — CRANE/GAD/AprAD). Not counted as a 12th cluster
   member; cluster stays at 11. Worth a second look when the correctness-tax
   cluster's fix-side related work gets drafted too: DOMINO's subword-
   alignment fix is a second distributional-bias mechanism alongside GAD's
   sampling-bias account, not filed there this iteration since that cluster
   was just swept iter 45.

- **arXiv 2608.10137 / "The Parser Already Knows: Lightweight Bias
  Correction in Constrained Decoding"** (UCLA — Ozgu, Wu, Van den Broeck,
  Kim) — bare since 2026-08-14 (iter 1-2), never annotated. Grammar-
  constrained decoding's rigid masking distorts the LM's true distribution;
  the parser/lexer state already computed for masking also encodes future
  grammatical validity, so the authors train a lightweight offline logit
  correction conditioned on that state, restoring probability mass masking
  removes at negligible extra cost — outperforms both raw masking and
  expensive online resampling. Now annotated: **differentiate-from** —
  belongs to the correctness-tax cluster's fix-side, same distributional-
  sampling-bias family as GAD (2405.21047) and CRANE, a fifth independent
  mechanistic account/fix for that cluster. No edge/Joules angle.
