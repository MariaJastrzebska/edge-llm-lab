**1. The Structured Output Benchmark (SOB)** (arXiv 2604.25359, Apr 2026) —
**cite.** A 7-metric multi-source benchmark (schema compliance, value
accuracy, faithfulness, structural completeness/coverage, type safety, strict
precision) spanning text, OCR'd-image, and audio-conversation inputs, all
normalized to text before scoring so it isolates structured-output capability
from vision/speech quality. Headline finding: Value Accuracy drops from 84.5%
(text) to 67.2% (image) to 23.7% (audio) — a new axis (input-modality
degradation) the existing correctness-tax cluster hadn't captured. Also
notes model size doesn't predict quality (Phi-4 14B beats GPT-5 on Value
Accuracy). Cloud-scale models throughout (GPT-5, GPT-5 Mini, Phi-4), no
edge/latency/energy measurement anywhere — **not competitive** with G1/Route
A's hardware-cost claim, but it's a well-built benchmark the eventual paper
can cite both for the general "structure costs accuracy" framing and,
specifically, as a reason the audio/image-modality angle (adjacent to Route
A's vision-modality choice) already has an accuracy-side benchmark, so
Route A's own contribution needs to stay clearly on the systems/hardware-cost
side to avoid looking redundant with SOB.

**2. Stay Within Your Bounds: Distance-Guided Decoding for Guaranteed
Context-Free Grammar Compliance** (arXiv 2608.28229, posted ~3 days ago per
its own metadata — the newest item swept this loop to date) —
**differentiate-from.** Precomputes bounded pushdown-automata reachability
labels and upper-bound acceptance-distances offline; uses them online to
guide horizon-aware pruning and beam search for CFG-constrained decoding
(tested on JSON, SQL, and Linear Temporal Logic). Fixes a real gap in
existing "local prefix feasibility" decoders: under tokenizer/grammar
mismatch and a finite token budget, a prefix can look locally extendable but
still be unable to reach a valid completion — this decoder guarantees every
output is grammar-accepted and reports improved completion quality over
baselines. No edge hardware, no Joules, no per-token mask-computation-cost
number anywhere in what's findable via WebSearch — this is a correctness/
completion-quality contribution, not a hardware-cost one. Joins the
**algorithmic mask-speedup cluster** (PSC, GRID, Attention-Meets-
Reachability, Token-Space-Compression, Pre³, XGrammar-2, MetaJuLS) as its
**7th member** — same defining trait as every other entrant: a genuine
grammar-decoding-mechanism contribution benchmarked without an edge/
single-stream/hardware-cost framing.
