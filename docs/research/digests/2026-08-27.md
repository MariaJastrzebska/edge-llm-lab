## 2. Targeted novelty check: has anyone applied hetero-core (CPU/GPU/NPU)
   scheduling specifically to grammar/schema **mask computation** since
   Ghidorah (arXiv 2505.23219, iter 19's find)?

**Verdict: still no.** Searched directly for the combination (grammar/schema
constrained decoding + mask + NPU/hetero-core/speculative) and broadened to
recent CPU/GPU/NPU heterogeneous-execution papers generally. Found a lot of
hetero-core **speculative decoding** work (a well-populated, active cluster)
and zero hits that touch grammar/schema mask computation with hetero-core
scheduling. This is a second independent negative result confirming iter
19's finding: the design-inspiration link this loop drew (speculative-
decoding hetero-core scheduling → mask-computation hetero-core scheduling)
has not been made by anyone else found so far. Route A's open gap stays
unclaimed.

Four new-to-`seen.json` items, all hetero-core/NPU speculative-decoding
cluster members (same shelf as Ghidorah/Dovetail-class work), **none**
touching grammar/mask — all scored **differentiate-from** (cite as
"hetero-core scheduling is an active technique class on this hardware,
just not yet applied to mask computation" evidence, strengthens rather
than threatens the gap):

  speculative decoding for LLM inference; predates even Ghidorah, an
  earlier member of the same technique family.
- **AHASD** (arXiv 2604.25326) — Asynchronous Heterogeneous Architecture
  for LLM Adaptive Drafting Speculative Decoding, mobile-device-specific.
- **Accelerating OpenPangu Inference on NPU via Speculative Decoding**
  (arXiv 2603.03383) — NPU-specific speculative decoding, another hetero-
  core cluster member.
- **Efficient On-Device Diffusion LLM Inference with Mobile NPU** (arXiv
  2606.13740) — lower relevance: diffusion-LLM paradigm, not autoregressive
