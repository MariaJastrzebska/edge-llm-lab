## New-to-seen.json items

1. **Constrained Decoding Eliminates Structural Failures in Small LLMs but
   Reveals a Scale-Dependent Semantic Gap** (arXiv 2609.23742, submitted
   2026-09-20)
   Link: https://arxiv.org/abs/2609.23742
   Relevance: benchmarks 5 models/3 families, **0.6B–4B parameters**, across
   14 structured-output tasks under native/Outlines/XGrammar decoding, with a
   two-axis evaluation separating structural (schema) from semantic (content)
   correctness — Maria's own standing "validity vs. correctness" grading
   requirement, done as a real study. Constrained decoding eliminates ALL
   structural failures (schema validity 78.6–92.9% → 100%) but a semantic gap
   persists and is scale-dependent: type-coercion failures are fully
   CD-rescuable, instruction-semantic failures (multi-step function calling)
   are CD-resistant; a constrained 1B can exceed an unconstrained 3B, yet the
   same constraint still helps the 3B too.
   Verdict: **differentiate-from/cite** — headline find this sweep. The most
   directly on-point correctness-tax paper yet for Maria's own sub-1B–4B
   regime, and its two-axis eval design is close to what the harness-OS
   paper's own correctness-grading gate needs to do. Not a scoop — accuracy-
   only study, no edge-hardware/latency/Joules measurement, so not competitive
   with G1's mechanism.

2. **Capacity, Not Format: Rethinking Structured Reasoning Failures**
   (arXiv 2606.09410, submitted 2026-06-08)
   Link: https://arxiv.org/abs/2606.09410
   Relevance: reframes the correctness-tax/format-tax narrative — format cost
   is capacity-dependent, not inherent to structured output. Strong models
   (Sonnet) absorb JSON constraints without degradation; models near their
   capacity limit degrade sharply (Haiku −36.2pp, largely truncation-driven).
   Uses information-matched prose controls + a 4-level schema-complexity
   gradient to separate format effects from prompt-length confounds.
   Verdict: **differentiate-from/cite** — converges with "Lost in Space"
   (iter 42) and #1 above on the same "weaker/smaller models pay more" shape,
   directly on point for Maria's sub-1B regime. Cloud-model comparison
   (Sonnet/Haiku), no edge/latency angle.

3. **Beyond Fluent Generation: A CPU Reliability Benchmark for MCP-Style Tool
   Calling in Sub-2B Small Language Models for Edge Deployment**
   (arXiv 2609.07370, submitted 2026-09-07)
   Link: https://arxiv.org/abs/2609.07370
   Relevance: benchmarks five open-weight sub-2B models on CPU — Phi-1.5,
   Pythia-1.4B, TinyLlama-1.1B-Chat, **Qwen2.5-0.5B, Qwen2.5-1.5B** (the
   Qwen2.5 pair overlaps Maria's own 005 pilot model set) — 100 MCP-style
   tool-calling prompts, under **native (unconstrained) decoding + a post-hoc
   recovery parser**, not grammar-constrained decoding. Only Qwen2.5-1.5B
   exceeds 70% recoverable success; strict raw JSON validity is 0.5%
   lab-wide; even the best model has only 5/1000 raw outputs directly
   parseable, exposing near-total dependence on the recovery parser.
   Verdict: **differentiate-from/cite** — a genuine sub-2B + CPU-edge +
   tool-calling reliability data point, but it's evidence *for* grammar-
   constrained decoding's problem statement (native decoding is nearly
   unusable without a parser), not a competitor to it. No grammar/mask angle,
   no energy telemetry — first sub-2B MCP-tool-calling CPU-edge benchmark on
   file.
